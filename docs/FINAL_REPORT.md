## 改造内容

### 🕒 时间管理系统

- **8 天 × 3 时段 = 24 个时间段**（腊月二十九 → 正月初六）
  - 每段 1 个活动（上午 / 下午 / 晚上）
  - 时间段循环推进：上午 → 下午 → 晚上 → 次日上午
- **精力值系统（0-100）**
  - 每活动消耗精力（10-20 点 / 段）
  - 整日结束时恢复 10 点
  - 精力归零时无法继续活动
- **红包钱系统**（¥2000 起步）
  - 主线事件 / 亲戚给红包 → 增
  - 礼物 / 投资 → 减
- **人情债系统**（0-10 实心点）
  - 拒绝亲戚请求 → +1
  - 答应请求 / 帮忙办事 → -1

### 📊 属性系统

- **5 大养成属性**（0-100）
  - 🏠 家庭（Family）
  - 💼 事业（Career）
  - 🌱 独立性（Independence）
  - 💕 浪漫值（Romance）
  - 🛡️ 抗压力（Resilience）
- **6 个 NPC 好感度**
  - 👩 妈妈（Mom）
  - 👨 爸爸（Dad）
  - 👵 奶奶（Grandma）
  - 👭 闺蜜 / 兄弟（Bestie）
  - 💔 前任（Ex）
  - 💐 相亲对象（Blind Date）
- **技能检定系统**（成功率 10%-90%）
  - 基于属性值对比难度阈值
  - 成功 / 失败产生不同剧情分支
  - 影响属性 / 好感度 / 资源

### 🎬 剧情内容

- **20 章主线 + 30 个过渡章节**
  - 第 1-4 章：春节前奏（抢票 / 年夜饭 / 拜年 / 老同学聚会）
  - 第 5-10 章：核心冲突（前任 / 相亲 / 父母谈心 / 返程）
- **15 种结局**（4 大类）
  - 🏆 混合线（mixed）：3 种
  - 🏠 家庭线（family）：3 种
  - 💕 爱情线（romance）：5 种
  - 💼 事业线（career）：4 种
- **8 条支线任务**
  - 奶奶的智能手机 / 教奶奶视频通话
  - 闺蜜的秘密 / 陪伴与倾听
  - 妈妈的回忆 / 修复家庭相册
  - 表哥的相亲直播间 / 偶然的缘分
  - 老同学创业邀请 / 选择站队
  - 爸爸的旧时光 / 父子深夜谈心
  - 奶奶的健康检查 / 安排体检
  - 前任的最后一封信 / 告别与和解
- **15 个随机危机事件**
  - 高压情境：老板电话 / 前任来电 / 亲戚借钱 / 突发病情
  - 每个事件 2-3 个选项
  - 多维效果（属性 + 好感度 + 资源）
  - 部分含技能检定

## 关键技术决策

1. **属性存储位置**：5 大属性同时存在于 `stats` 顶层与 `stats.attributes`，向后兼容旧逻辑。
2. **NPC 好感度命名**：`npc_mom_affection`（顶层）与 `stats.npcs.npc_mom`（旧）共存。
3. **结局优先级**：mixed → family → romance → career，越靠前越优先匹配。
4. **危机事件触发**：每章推进 10% 概率插入。
5. **技能检定公式**：`successRate = clamp((attr - difficulty + 50) / 100, 0.1, 0.9)`。
6. **支线任务激活**：特定主线 quest 完成后自动激活，不打断主线节奏。
7. **HUD 渲染**：每次状态变化后调用 `refreshHUD()`，保证 UI 实时同步。
