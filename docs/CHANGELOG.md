#### 核心函数
```javascript
// 性别归一化
normGender(g) → "女" | "男"

// 获取性别化 NPC 池
getNPCPool(gender) → NPC[]

// 获取特定 NPC 的性别化版本
getGenderedNPC(npcId, gender) → NPC

// 获取默认好感度
getDefaultAffinities(gender) → {npcId: affinity}
```
