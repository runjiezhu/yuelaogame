# 月老养成 · 婚恋模拟器

一个基于真实婚恋经验的文字冒险游戏。

**在线游玩：https://zhuru-yuelao.github.io/yuelaogame/**

（游戏部署在 GitHub Pages，打开即可玩，不需要本地服务器）

---

## 游戏简介（v2 · 春节特别版）

你的开局画像、剧情分支、经验金句，全部来自 980 条真实红娘连麦案例。

**新增春节主线**：从腊月二十九到正月初八，10 章节串联完整的春节催婚经历。

**新增 6 个固定 NPC**：妈妈、爸爸、奶奶、闺蜜小敏、前任一凡、相亲对象林晓。每次选择都会影响你与他们的好感度，并决定你的结局走向。

每局随机生成一个角色卡（12种原型），在春节主线 + 40 条散装婚恋案例中做选择，最终走向 15 种结局之一（含 6 个春节专属结局）。

适合婚期 23-35 岁，一局 15-25 分钟。

## 快速开始

### 在线玩（推荐）
打开 https://zhuru-yuelao.github.io/yuelaogame/ 即可游玩，无需安装任何东西。

### 本地运行
```bash
# 安装依赖
npm install

# 启动本地服务器
node scripts/serve.mjs
# 打开 http://localhost:8765/
```

## 核心系统

### 春节主线（10 章节）
腊月二十九 → 除夕 → 初一 → 初二 → 初三 → 初四 → 初五 → 初六 → 初七 → 初八

主线优先触发，每章完成自动解锁下一章。10 章全部完成后触发「年度战役幸存者」结局。

### NPC 好感度系统
6 个固定 NPC，每人有独立好感度（0-100）。选择不同选项会增减好感度，影响结局走向。

| NPC | 初始好感 | 触发结局 |
|---|---|---|
| 妈妈 | 50 | 好感≥60 →「家庭和解」 |
| 爸爸 | 50 | |
| 奶奶 | 50 | |
| 闺蜜小敏 | 50 | |
| 前任一凡 | 30 | 好感≥65 →「前任和解」 |
| 相亲林晓 | 30 | 好感≥70 →「相亲上岸」 |

### 结局系统（15 种）
**春节专属结局（6）**：年度战役幸存者、回乡过年战士、逃离大师、相亲上岸、前任和解、家庭和解

**经典结局（9）**：门当户对的圆满、主动选择的单身贵族、相亲不息的循环等

## 技术栈

- 纯原生 HTML/CSS/JavaScript（ES Module，无框架）
- 零依赖静态文件，部署到任意静态托管服务
- GitHub Pages 自动部署

## 部署说明

1. 将项目推送到 GitHub
2. 在仓库 Settings → Pages → Source，选择 `main` branch，Save
3. 访问 `https://<你的用户名>.github.io/yuelaogame/`

**注意**：GitHub Pages 部署需要将代码放在仓库根目录（不是 `docs/`）。如需使用 `docs/` 部署方式，改为选择 `main` branch 的 `/docs` 文件夹。
